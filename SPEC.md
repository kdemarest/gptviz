## Overview

gptviz: Obsidian plugin for AI image generation driven by markdown in `canvid/`.
- Obsidian is the editor and file picker. gptviz reads the current Prompt, loads reference images, generates candidates, browses and promotes them, and checks dependencies.
- Owns the Mode Ribbon: see `Spec-ModeRibbon.md`.
- Fail loud. Android-compatible. Planned work: `PLAN.md`.
